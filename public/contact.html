CoAuth is an open-source project built for the OpenAI WebMCP Challenge. The best way to reach the maintainers, report a problem, request a feature, or ask a question about the WebMCP tool surface is through the project's issue tracker on GitHub.

  • Issues & support: github.com/lazycheese/coauth/issues
  • Source code: github.com/lazycheese/coauth
  • Email: support@coauth.vercel.app

For questions about integrating an agent with this site, start with the agent instructions, the llms.txt summary, and the OpenAPI specification. The developer portal has a quickstart and example requests. We aim to respond to issues within a few business days. When reporting a problem, please include the tool you called, the arguments you sent, and the response you received so we can reproduce it quickly.
